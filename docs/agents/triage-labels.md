# Triage labels

| Role and label    | Meaning                                                 |
| ----------------- | ------------------------------------------------------- |
| `needs-triage`    | Awaiting maintainer evaluation                          |
| `needs-info`      | Awaiting information                                    |
| `ready-for-agent` | Approved, bounded delivery work with completed blockers |
| `ready-for-human` | Work requiring a human                                  |
| `wontfix`         | Work that will not be pursued                           |

Labels express readiness within the owning workflow. A label on a map or
specification does not authorize implementing its children.
